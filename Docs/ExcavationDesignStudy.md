# 掘进构型、干砂验证与底盘滑移：第一轮研究

> 后续实现与实测见 [第二轮试验平台](ExcavationLabV2.md)。本文保留第一轮审计时点：其中“未实现剪胀/共旋”“只有四种刀头”和启动选择行为已被第二轮更新；旧材料路径及历史试验结论仍按原时点理解。

日期：2026-09-13。对象：本仓库 Unreal/MPM 原型，地球重力下干砂开挖。本文区分厂家用途、论文结果、源码事实与待验证假设。不是系统综述，也不是已经完成实验标定的机械选型报告。

## 1. 结论与工作范围

值得把游戏发展为“机构—土体—底盘”共同参与的试验平台。当前适合检查接触输送是否成立、发现积料与几何问题，不足以凭一次游玩排名真实机械效率。现阶段最紧迫的问题是反力耦合、土体标定和比较口径，而不是继续全面提高显示精度。

本轮加入 Paddle、Chevron、Spoke、Helix 四个可启动的几何原型；后三者为新增。它们共用原来的底盘、输送链和有限扭矩电机，接触几何与显示几何相同。新增角度/安装高度参数、材料敏感性参数、原始反力与底盘实际反馈诊断。原型不是厂家产品复制品，尤其 Spoke 不是完整盾构、Helix 不是连续螺旋叶片。完整杯斗、连续螺旋、独立支护排渣与链斗开沟机构仍属于后续机械设计，不能把本轮几何对照称为已实现全部市场构型。

这一组资料支持“几何、工况、土性共同影响性能”，不支持“φ大就选螺旋、φ小就选刀盘”的简单规则。须区分 φ（土内部抗剪）、δ/μ（土与钢界面）、密实度/孔隙比、剪胀ψ及黏聚c。它们不是同一个摩擦系数。

建议按以下场景组织比较，表中是研究假设而非厂家保证：

| 场景 | 可能主导的困难 | 优先对照 | 必测量 |
|---|---|---|---|
| 松散、易流动、c≈0干砂 | 回流、撒漏、履带沉陷 | 兜砂斗轮、带外壳螺旋与开放拨轮 | 净收料率、回填、沉陷；不能只测切削力 |
| 较密实/较高φ的干砂 | 较大抗剪与剪胀，切削负载上升 | 小进给刀鼓、分散切入齿、浅切多次 | Fx/Fz、扭矩峰值、剪胀和每转进给 |
| 同一砂体但不同土—钢摩擦 | 打滑空转或输送阻力变化 | 螺旋外壳/叶片、斗壁表面 | 轴向流率、空转比、扭矩；φ保持不变 |
| 同一砂体但低机重/支承不足 | 机器先移动、刀具无法进给 | 对向工作头、可收放支承、合理配重 | 净力/力矩、有效推进与位移 |

较大φ可能同时增加切削阻力和地面抗剪能力，整机效果取决于两者相对变化；不能假定只会“更难挖”或“更能抓地”。首次参数扫描可取φ=30/35/40°、c=0，并固定其余量；这是人为设置的敏感性点，不是三种经过实测标定的砂。当前硬化变量不能等同真实相对密实度Dr。

## 5. 滑移：如何验证用户提出的角度解释

用户的解释是合理假设，但目前还不能判定为唯一原因。组件向下转动同时增加埋深、改变瞬时刀面方向和反力作用臂；前方壳体也可能直接顶住砂。持续按油门与松开油门会触发不同辅助阻力，挖掘机的间歇动作可能因此看起来更稳。

平地准静态分析可先用 `N≈mg−Fz`、`F可用≈min(F驱动上限, μ有效N)` 作诊断近似：Fz定义为土对机器向上的力。向上反力可能卸载履带，向下反力可能增加法向载荷，但还会改变俯仰和前后载荷。这不是完整履带地面力学；可变形砂中的沉陷、履刺被动阻力和剪切动员还需另建模型。

建议依次做：

1. **固定底盘单刀/工作头试验**：分别保持切深不变改变刀面角、保持角度不变改变切深。先去掉底盘滑移干扰，测Fx/Fz/扭矩和有效挖掘量。
2. **自由底盘同工况**：记录前后位移、前进速度、支承载荷、原始和实际施加反力。不能仅看相机跟随画面。
3. **驱动与刹车对照**：空转、停机推进、旋转不推进、旋转推进、制动保持；另测硬地/砂地直线牵引。
4. **变量矩阵**：初筛安装俯仰0/−8/−15°，但通过安装高度补偿使实际切深一致；切深先按D的0.1/0.2/0.3设置并记录实际值；再扫描v/(ωR)。这是建议的试验设计，不是论文推荐最优角。
5. **改机构再调底盘**：浅切多次、降低每转进给、刮刀前角/退让角、避免壳体先碰砂、改善排料；再比较增加支承面积/合理配重/可收放支腿，或两工作头反力平衡。每项修改均需测量代价。

目前新增日志只记录机身速度和位移，没有履带带速，因此不能把它命名为“滑转率”。以后有实际带速u后，在非零速度工况定义并公布符号约定，例如前进驱动时s=(u−v)/max(|u|,ε)。原地被推走另记被动滑移距离，不混进该公式。

## 6. 验证场景与优化顺序

| 门槛 | 试验 | 观测/接受方式 |
|---|---|---|
| A 数值正确 | 长时静置、自由落体、刚体旋转、无摩擦/有摩擦接触、封闭质量与冲量预算 | 质量误差、总动量、能量与数值保护触发；不能只验NaN |
| B 材料标定 | 同一批实物干砂的密度/粒径含水记录、堆积与坍塌、直剪/三轴、板贯入 | 同时约束摩擦、剪胀、密度、界面摩擦；堆积角不唯一决定φ |
| C 单刀验证 | 带水平/垂直测力的透明土槽，控制角度、深度与速度 | 平均和峰值Fx/Fz、力随位移曲线、扰动形状；用未参与拟合的工况交叉验证 |
| D 输送验证 | 固定头、统一进料与出口，转速/填充率对照 | 质量流量、滞留量、回填、堵塞占时、电机功；转得动不等于有效挖掘 |
| E 底盘验证 | 配重、坡面、牵引试验、履带沉陷，工具开/关 | 牵引—滑转、沉陷、反力矩、载荷转移；验证低负载/高负载/失去接触 |
| F 整机与玩法 | 同任务的自由驾驶，限制相同额定功率/机重或按规模归一化 | 任务时间、有效出渣、能耗、滑移与失败率，保留操作学习成本 |

误差容许值须结合传感器误差、重复性和用途设定；初期可把网格加密后均值变化小于5%、峰值小于10%作为项目暂定目标，不能宣称行业标准。原始实验至少重复3次作为初筛，并保存离散性；随机数种子与GPU非确定性也需记录。

物理精度优化：先在缩小的单刀土槽使用5/3.125/2.5 cm并同步减小时间步，再进一步细化关键间隙。每格物质点数量、网格尺度和时间步需分别做敏感性。更细网格应不改变材料刚度/强度以换稳定。优先稀疏/活动网格、减少全粒子同步回读、隔离显示重建；全沙箱盲目增加粒子数可能只降低帧率。APIC/FLIP或有限变形本构应通过基准试验选择，不能仅凭算法名称升级。

干砂范围内先补足密实度、非关联剪胀与应力客观性；若要研究粒径与刀缝同阶的堵塞/筛分，可对局部用DEM作交叉验证。地下水、黏土、破岩、月球低重力是独立扩展，不由当前干砂场景自动覆盖。

## 7. 指标与比较口径

- 有效开挖体积V：预定义世界坐标目标区内实际移除且未回填的体积；不能用显示网格颜色或机器后方现存砂代替。
- 实际收集质量M：越过固定出口并进入收集区的物质点质量，按身份去重；有反向流应同时记录净通量。
- 生产率Q=M/t；回填率=回到目标区的已移出质量/累计移出质量；收料率分母要明确是供料量还是开挖量。
- 平均/峰值切削力、扭矩波动、堵转占时；不要将1 Hz日志最大值当真实峰值。
- 单位开挖体积能耗：积分推进执行器功率与各电机τ·ω后除以V，同时明确正功/回生/制动的计数规则。当前尚无完整能量账本，不能从扭矩一个量计算总效率。
- 原始反力与施加底盘反力分开保存；固定台力是约束反力，不能当自由机器必然可承受。
- 机重、刀头D、切深d/D、v/(ωR)、F/(ρgD³)、τ/(ρgD⁴)、黏聚比c/(ρgD)有助于尺度比较；相似参数不能消除不同土体或边界条件的差异。

## 8. 已实现入口与后续边界

在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File Tools/PlayMachines.ps1 -Head Spoke
powershell -ExecutionPolicy Bypass -File Tools/PlayMachines.ps1 -Head Helix -Bench
powershell -ExecutionPolicy Bypass -File Tools/PlayMachines.ps1 -Head Chevron -HeadPitch -8 -HeadHeightCm 16
```

Head可选Paddle/Chevron/Spoke/Helix。进入选择界面后选掘进机；T启停，G反转，Q/E改变组件角度。安装高度单位cm；改变俯仰后仍须计算实际切深，参数独立不等于切深自动不变。启动器调用本机UE编辑器，不是新的USB打包版。

根目录也提供`PlayHeadPaddle.cmd`、`PlayHeadChevron.cmd`、`PlayHeadSpoke.cmd`、`PlayHeadHelix.cmd`。后两项默认带剖视检查视角，HUD标明罩壳物理接触仍存在；普通视图可直接运行上述PowerShell入口而不传`-InspectHead`。`-Phi 30 -CohesionPa 0`可通过启动器传入敏感性参数。

直接引擎命令可加 `-SandPhi=30 -SandCohesionPa=0 -SandToolMu=0.5 -SandDamping=0.65`，只改变指定项；这些是敏感性设置。`-SandDisableBucketCarry`可关闭挖掘机携砂辅助。剪胀角尚未实现，未提供会让人误以为生效的扫描开关。

`Tools/TestHeadVariants.ps1`生成`Saved/HeadVariants/results.json`和每组日志/截图，验证运行、质量、有限性、接触输送原型；不以出渣量自动判机械优劣。下一步完整实现的对象应在此几何筛选和单刀验证后确定；连续螺旋的碰撞表示、盾构的土仓、链斗的完整循环都需专门设计。
