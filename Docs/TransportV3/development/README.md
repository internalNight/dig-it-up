# Development evidence

These are archived measurements from exploratory runs, including failed designs.
Intermediate source trees were not archived. Binary identifiers distinguish builds,
but do not make those old builds reproducible from the final source. Source files
were sometimes edited while an earlier pilot binary was running; pilot startup
source hashes are therefore not claimed to identify the compiled source.

The final matrix under ../evidence uses an unchanged source snapshot and binary.
Do not mix this development ledger into a controlled head ranking or select only
successful exploratory runs. Full engine logs remain locally under Saved/TransportV3.
